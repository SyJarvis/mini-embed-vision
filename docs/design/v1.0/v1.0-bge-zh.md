# mini-embed-vision v1.0 — BGE-zh 中文版

> 设计时间：2026-08-21
> 文本编码器：`BAAI/bge-base-zh-v1.5`（冻结，102M，hidden=768）
> 视觉编码器：`openai/clip-vit-base-patch32`（可训练，87M）
> 输出维度：768

---

## 1. 概述

v1.0-bge-zh 是当前在用的稳定版本，专为**中文图文嵌入**场景设计。文本编码器冻结，只训练视觉编码器和投影层（或者 LoRA）。

## 2. 架构

```
文本输入 (中文)  → bge-base-zh-v1.5 (冻结) → [CLS] 768d → Identity → 768d L2-norm
图片输入         → CLIP-ViT-B/32 (可训练)   → [CLS] 768d → Identity → 768d L2-norm
                                                                          ↕ 对比学习
```

关键参数：
- `text_proj`：Identity（hidden=768 == embed_dim=768）
- `vision_proj`：Identity（hidden=768 == embed_dim=768）
- `logit_scale`：可学习的温度参数
- 可训练参数：**87M**（仅视觉编码器）

## 3. 数据

| 数据集 | 描述 | 数量 | 路径 |
|--------|------|------|------|
| ImageNet-zh | ImageNet-1k + VLM 中文描述 | 183k | `data/imagenet-1k-zh-captions/` |

数据链路：
1. `generate_image_caption.py` — VLM 生成中文描述（prompt 为中文）
2. `pack_imagenet_hf.py` — 打包 parquet
3. `data.py::MultimodalParquetDataset` — 训练加载

## 4. 训练

- 冻结文本编码器，仅训练视觉编码器
- CLIP 对比学习（InfoNCE loss，i2t + t2i 双向）
- DDP all_gather 全局负例
- bf16 混合精度
- 支持 LoRA 微调视觉编码器

## 5. Benchmark

| 任务 | 能跑 | 备注 |
|------|:----:|------|
| ImageNet-1k 分类 | ✅ | 纯视觉，不碰文本 |
| C-MTEB 中文检索（T2Retrieval 等） | ✅ | 中文 query → 中文文档 |
| C-MTEB 中文分类/STS/聚类 | ✅ | 纯文本任务 |
| **Flickr30k T2I 检索** | ❌ | 英文 query → bge-zh 乱码 |
| **Flickr30k I2T 检索** | ❌ | 英文文档 → bge-zh 乱码 |
| MTEB 英文任务 | ❌ | 全部依赖英文文本编码 |
| 跨语言检索 | ❌ | 无英文能力 |

## 6. 模型体积

| 组件 | 参数量 | 显存占用 (fp32) |
|------|--------|----------------|
| text_encoder（冻结） | 102M | ~408 MB |
| vision_encoder（可训练） | 87M | ~348 MB |
| 投影层 | 0（Identity） | — |
| **训练总显存** | **~189M** | **~5-6 GB**（含梯度/优化器/activations） |

## 7. 局限性

1. **仅有中文能力** — 英文、其他语言不支持
2. **benchmark 受限** — 跨模态检索任务无法验证
3. **数据量已饱和** — 183k 后 R@1 不再提升（v1.0 模型容量天花板）
4. **单投影层** — 非 T5 结构视觉时 projection 是单 Linear，容量有限

## 8. 典型用法

```bash
# 训练
python train.py --text-model BAAI/bge-base-zh-v1.5 --data-dir data/imagenet-1k-zh-captions

# Benchmark（仅中英文可跑的任务）
python benchmark/run_benchmark.py --checkpoint checkpoints/best.pth --tasks quick_image
python benchmark/run_benchmark.py --checkpoint checkpoints/best.pth --tasks quick
```
